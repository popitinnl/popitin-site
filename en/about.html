Dutch design, built in Europe.

Pop it in is built for a next generation of return infrastructure for Europe's deposit return schemes. We combine hardware engineering, payment and loyalty systems, IoT telemetry and fraud-prevention technology into a system that's simple for retailers to run and simple for operators to trust.

One platform

One RVM platform, fits anywhere.

We built the world's smallest web-connected RVM compactor platform — 55 cm wide, 65 cm deep and 50 cm tall, patent pending. That lets the same technology fit very different situations.

Why we do this

Deposit return works — when returning takes no effort.

Every bottle and can that comes back is material that doesn't end up in a verge or an incinerator. So we build machines that fit the places people already are — small enough for the corner shop, smart enough for a national scheme.
